# Local Resume

自分のPCで履歴書・職務経歴書を作成し、プレビューやPDF保存ができるアプリです。

個人情報をAIにも誰かのサーバーにも渡したくないけれど、経歴書の文章はAIにレビューしてもらいたい、という目的で作りました。氏名・連絡先・会社名・写真などはブラウザ内で暗号化し、AIに見せる経歴や自己PRの本文とは分けてローカルに保存します。

自由にコピー・改変して使ってください。

## 起動

Node.js 24以上を使用します。

```sh
npm install
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。

## 技術スタック

- Vite + TypeScript
- lit-html：画面と書類の描画
- Paged.js：A4の改ページ・プレビュー
- Web Crypto API：ブラウザ内での暗号化・復号
- Node.js：ローカルへの保存
- Noto Sans JP：ローカル配信の日本語フォント
